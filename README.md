# Condoo

Protótipo de app de condomínio feito em HTML, CSS e JavaScript puro.
Tem painel de síndico e de morador (reuniões, avisos, reservas e convidados).

## Ver online

Depois de ativar o GitHub Pages, o site fica em:

`https://SEU-USUARIO.github.io/condoo/`

(troque `SEU-USUARIO` pelo seu usuário do GitHub)

## Rodar no computador

Não precisa instalar nada. É só abrir o `index.html` no navegador.

## App Android

O `.apk` fica na aba **Releases** do repositório (não dentro das pastas).
É um app Capacitor que carrega esse mesmo `index.html`.

## Como atualizar o site

```bash
git add .
git commit -m "o que eu mudei"
git push
```

Em 1 ou 2 minutos o Pages publica a versão nova.
